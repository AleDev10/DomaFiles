# 📁 DomaFiles

Um aplicativo moderno e intuitivo para transferência segura de ficheiros entre dispositivos.

## 📋 Sobre o Projeto

**DomaFiles** é uma aplicação desenvolvida em JavaScript que permite aos utilizadores transferir ficheiros de forma rápida, segura e eficiente. A plataforma oferece uma experiência de utilizador amigável e funcionalidades avançadas para gerir transferências de ficheiros.

### 🎯 Características Principais

- ✨ **Interface Intuitiva** - Experiência de utilizador limpa e fácil de usar
- 🚀 **Transferências Rápidas** - Otimizado para velocidade
- 🔒 **Segurança** - Protocolo seguro de transferência
- 📱 **Compatibilidade** - Funciona em múltiplos dispositivos
- 🎨 **Design Moderno** - Interface responsiva e agradável

## 🛠️ Tecnologias Utilizadas

- **JavaScript** - Linguagem principal do projeto (100%)
- **MIT License** - Licença de código aberto

## 📦 Instalação

### Pré-requisitos

- Node.js (versão recomendada: 16+)
- npm ou yarn

### Passos de Instalação

```bash
# Clonar o repositório
git clone https://github.com/AleDev10/DomaFiles.git

# Navegar para o diretório
cd DomaFiles

# Instalar dependências
npm install

# Iniciar a aplicação
npm start
```

## 🚀 Como Usar

1. Abra a aplicação no seu navegador
2. Selecione os ficheiros que deseja transferir
3. Escolha o dispositivo de destino
4. Confirme a transferência
5. Aguarde a conclusão do processo
